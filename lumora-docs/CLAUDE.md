# Lumora Docs Claude Rules

Before editing:
1. Read this file and relevant docs first.
2. Do not mention KPM as part of the system name.
3. Use "Lumora Academy" as the product name.
4. Mention Malaysian curriculum references only as alignment/reference where needed.
5. Do not copy copyrighted textbooks, workbooks, diagrams, paid notes, or exam papers.
6. Prioritize child safety, privacy, accessibility, accuracy, and maintainability.
7. Documentation must be clear for developers, AI agents, educators, and future contributors.
8. Use Markdown.
9. Keep decisions traceable through ADRs.
10. Verify before saying complete.
