# Release Notes

## Purpose

A changelog of what shipped, when — for people, not machines.

## Status

Version: 0.1 — nothing has shipped yet; every application repo (`lumora-api`, `lumora-academy`, etc.) is still a placeholder. This page starts recording entries once the first Phase 1 feature clears [Testing & QA](../14-testing-qa/index.md#release-readiness)'s release-readiness gate.

## Format convention

One entry per release, newest first: date, the [Roadmap](../25-roadmap/index.md) phase it belongs to, and a short plain-language summary of what changed — not a raw commit list. An entry is only added once its feature has actually cleared the release-readiness gate in [Testing & QA](../14-testing-qa/index.md#release-readiness), not when code merges.
