# Templates

## Purpose

Reusable starting points for the two recurring documentation artifacts [Development Standards](../08-development-standards/index.md#feature-workflow) requires: an ADR for binding decisions, a feature spec for non-trivial features. Copy one rather than writing either from scratch.

## Status

Version: 1.1 foundation draft. Two templates exist; add more only when a genuinely recurring documentation need shows up — not speculatively.
